# Kebijakan privasi

Nekoyomi adalah aplikasi gratis dan sumber terbuka.
Aplikasi ini disediakan tanpa biaya dan dimaksudkan untuk digunakan apa adanya.

Halaman ini menjelaskan data apa saja yang ditangani oleh **aplikasi Nekoyomi** dan **situs web Nekoyomi**.
Singkatnya: kami tidak mengumpulkan apa pun tentang Anda.

Ini adalah terjemahan. Jika ada perbedaan, yang berlaku adalah [versi bahasa Inggris](https://nekoyomi.seguaz.online/privacy/).

## Aplikasi {#the-app}

### Tanpa analitik, tanpa pelacakan, tanpa akun {#no-analytics-no-tracking-no-accounts}

Aplikasi ini **tidak berisi layanan analitik, iklan, maupun pelaporan crash**.
Tidak ada akun Nekoyomi, dan kami tidak menjalankan server apa pun yang menerima data Anda.

Pustaka, riwayat, kategori, pengaturan, dan cadangan Anda **hanya disimpan di perangkat Anda** (dan di tempat mana pun Anda memilih untuk menyimpan cadangan).

### Log kerusakan {#crash-logs}

Jika aplikasi mengalami crash, tidak ada data yang dikirim ke mana pun secara otomatis.
Anda dapat membuat log kerusakan sendiri dari <nav to="advanced"> dan memutuskan apakah akan membagikannya, misalnya saat melaporkan bug.
Tinjau log tersebut sebelum dibagikan, karena log mungkin berisi detail tentang perangkat dan konfigurasi aplikasi Anda.

### Koneksi jaringan yang dibuat oleh aplikasi {#network-connections-made-by-the-app}

Aplikasi hanya terhubung ke internet untuk melakukan apa yang Anda minta:

- **Sumber dan ekstensi** yang Anda pasang, serta **repositori ekstensi** yang Anda tambahkan, untuk menjelajah, membaca, menonton, dan mengunduh konten.
  Semua ini adalah layanan pihak ketiga yang tidak dioperasikan oleh kami.
- **Pelacak** (mis. MyAnimeList, AniList) dan layanan opsional lainnya, hanya jika Anda masuk ke layanan tersebut atau mengaktifkannya.
- **OpenSubtitles**, hanya saat Anda mencari subtitel dari pemutar video. Pencarian ini mengirimkan judul, nomor musim dan episode jika diketahui, serta bahasa subtitel, tanpa akun apa pun.
- **GitHub**, untuk memeriksa pembaruan aplikasi dan mengunduhnya.

Masing-masing layanan ini memiliki kebijakan privasinya sendiri, yang sebaiknya Anda tinjau.

## Situs web ini {#this-website}

Situs web ini adalah situs statis yang di-hosting di **GitHub Pages**.

- Situs ini **tidak menggunakan cookie, analitik, maupun skrip pihak ketiga**.
- Pilihan tema terang/gelap Anda hanya disimpan di browser Anda sendiri.
- Seperti layanan hosting web lainnya, GitHub dapat memproses data teknis seperti alamat IP Anda untuk menayangkan situs dan menjaga keamanannya.
  Lihat [pernyataan privasi GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

## Tautan eksternal {#external-links}

Baik aplikasi maupun situs web ini berisi tautan ke situs lain yang tidak dioperasikan oleh kami.
Kami tidak memiliki kendali atas, dan tidak bertanggung jawab atas, konten, kebijakan privasi, atau praktik situs-situs tersebut.

## Perubahan pada kebijakan privasi ini {#changes-to-this-privacy-policy}

Kami dapat memperbarui kebijakan privasi ini dari waktu ke waktu.
Setiap perubahan akan dipublikasikan di halaman ini.

Versi kebijakan ini berlaku sejak 19 November 2026.
