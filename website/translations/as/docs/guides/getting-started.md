# আৰম্ভণি

Nekoyomi ছেট আপ কৰাত আপোনাক সহায় কৰিবলৈ প্ৰয়োজনীয় তথ্য।

## ইনষ্টলেচন গাইড {#installation-guide}

### Nekoyomi ডাউনলোড কৰা {#downloading-nekoyomi}

1. **Nekoyomi**-ৰ শেহতীয়া সংস্কৰণ পাবলৈ আমাৰ [ডাউনলোড](/download/) পৃষ্ঠালৈ যাওক।
2. ডাউনলোড সম্পূৰ্ণ হোৱাৰ পিছত `.apk` ফাইলটো খোলক।
3. ইনষ্টলেচন প্ৰক্ৰিয়াটো সম্পূৰ্ণ কৰক।

### উৎস যোগ কৰা {#adding-sources}

আপোনাৰ ডিভাইচত **Nekoyomi** ইনষ্টল হোৱাৰ পিছত, আপুনি বিভিন্ন উৎসৰ পৰা পঢ়িবলৈ নিজৰ বিষয়বস্তু আনিব পাৰে:

:::: tabs
== স্থানীয় উৎস
আপোনাৰ ডিভাইচত স্থানীয়ভাৱে সংৰক্ষিত বিষয়বস্তু পঢ়ক বা চাওক।

নিৰ্দেশনাৰ বাবে স্থানীয় উৎসৰ গাইডসমূহ চাওক:
- [মাঙ্গা](/docs/guides/local-manga-source/)
- [এনিমে](/docs/guides/local-anime-source/)

== বাহ্যিক ৰেপ’জিটৰী
বাহ্যিক ৰেপ’জিটৰীয়ে **Nekoyomi**-ত অতিৰিক্ত উৎস যোগ কৰে। <nav to="browse"> খুলি **এনিমেৰ এক্সটেনশ্যন ৰেপ’**/**মাঙ্গাৰ এক্সটেনশ্যন ৰেপ’** টিপি আপুনি বাহ্যিক ৰেপ’জিটৰী যোগ কৰিব পাৰে।

তাত, `index.min.json`-ৰে শেষ হোৱা URL দি আপুনি ৰেপ’জিটৰী যোগ কৰিব পাৰে।

::: danger সাৱধান
Nekoyomi-এ কোনো অনানুষ্ঠানিক ৰেপ’জিটৰীৰ বাবে সমল প্ৰদান নকৰে। মনত ৰাখিব যে যিকোনো তৃতীয় পক্ষৰ ৰেপ’জিটৰী বা এক্সটেনশ্বনে এপটোৰ সম্পূৰ্ণ প্ৰৱেশাধিকাৰ পাব আৰু সেইবোৰত মেলৱেৰ থাকিব পাৰে।
:::

এটা ৰেপ’জিটৰী যোগ কৰাৰ পিছত, <nav to="extensions"> খুলি এক্সটেনশ্বনৰ তালিকাখন ৰিফ্ৰেশ্ব কৰক।

এতিয়া এক্সটেনশ্বনবোৰ ইনষ্টল কৰিবলৈ সেইবোৰৰ কাষত থকা ডাউনলোড বুটামটো টিপিব পাৰে।

> আপুনি [তৃতীয় পক্ষৰ ইনষ্টলেচন সক্ষম কৰিব](/docs/faq/browse/extensions#enabling-third-party-installations) লগা হ’ব পাৰে।

== মেনুৱেল এক্সটেনশ্বন
`.apk` ফাইলৰ জৰিয়তে এক্সটেনশ্বনসমূহ মেনুৱেলি ইনষ্টল কৰিব পাৰি।

::: danger সাৱধান
Nekoyomi-এ কোনো অনানুষ্ঠানিক এক্সটেনশ্বনৰ বাবে সমল প্ৰদান নকৰে। মনত ৰাখিব যে যিকোনো তৃতীয় পক্ষৰ ৰেপ’জিটৰী বা এক্সটেনশ্বনে এপটোৰ সম্পূৰ্ণ প্ৰৱেশাধিকাৰ পাব আৰু সেইবোৰত মেলৱেৰ থাকিব পাৰে।
:::

### আপোনাৰ পুথিভঁৰালত ছিৰিজ যোগ কৰা {#adding-series-to-your-library}

বিচৰা এক্সটেনশ্বনটো ইনষ্টল কৰাৰ পিছত, আপুনি ইয়াক **মাঙ্গাৰ উৎস**/**এনিমেৰ উৎস** টেবত পাব।

আপোনাৰ পুথিভঁৰালত ছিৰিজ এনেদৰে যোগ কৰিব পাৰে:

1. আপুনি ব্ৰাউজ কৰিব বিচৰা উৎসটো বাছনি কৰক।
2. ব্ৰাউজ কৰিবলৈ আপুনি **জনপ্ৰিয়**/**সৰ্বশেষ** তালিকা ব্যৱহাৰ কৰিব পাৰে, অথবা ছিৰিজৰ নামেৰে সন্ধান কৰিব পাৰে।
3. যোগ কৰিব বিচৰা ছিৰিজটো বিচাৰি পোৱাৰ পিছত, অধিক সবিশেষৰ বাবে ইয়াত টিপক।
4. "**লাইব্ৰেৰীলৈ যোগ কৰক**" বুটামটো টিপক, আৰু ছিৰিজটো আপোনাৰ পুথিভঁৰালত যোগ হ’ব, পঢ়িবলৈ/চাবলৈ সাজু!

## অতিৰিক্ত ছেটআপ {#additional-setup}

### ছিৰিজ সন্ধানৰ বিকল্পসমূহ {#series-search-options}

যদি আপুনি আপোনাৰ সকলো উৎসত ছিৰিজ সন্ধান কৰিব বিচাৰে, তেন্তে সৰ্বভৌম সন্ধান সুবিধাটো ব্যৱহাৰ কৰিব পাৰে।

এই পদক্ষেপসমূহ অনুসৰণ কৰক:

1. "**ব্ৰাউজ কৰক**" অংশলৈ যাওক।
2. নিশ্চিত কৰক যে আপুনি ওপৰৰ সোঁফালৰ চুকত থকা "**উৎসসমূহ**" টেবত আছে।
3. সকলো উপলব্ধ উৎসৰ পৰা ছিৰিজ বিচাৰিবলৈ টুলবাৰৰ সন্ধান আইকনটো ব্যৱহাৰ কৰক।

### কোনো নিৰ্দিষ্ট ছিৰিজ বিচাৰি পোৱাত অসুবিধা হৈছে নেকি? {#trouble-finding-a-specific-series}

কোনো নিৰ্দিষ্ট ছিৰিজ সন্ধান কৰোঁতে অসুবিধাৰ সন্মুখীন হ’লে, তলৰ কথাবোৰ বিবেচনা কৰক:

<!-- markdownlint-disable MD004 -->
* আপোনাৰ বানান পুনৰ পৰীক্ষা কৰি আকৌ চেষ্টা কৰক, কিয়নো কিছুমান উৎসই **ইংৰাজী** শিৰোনামৰ সলনি **জাপানী ৰোমানাইজড** শিৰোনাম ব্যৱহাৰ কৰিব পাৰে।
  > উদাহৰণ: **My Hero Academia**-ৰ সলনি **Boku no Hero Academia**।

* কিছুমান উৎসই শিৰোনামৰ বাবে বেলেগ বানান বা শব্দ ব্যৱহাৰ কৰিব পাৰে।
  > উদাহৰণ: **Bungou Stray Dogs**-ৰ সলনি **Bungo Stray Dogs**

  > উদাহৰণ: **Sangatsu no Lion**-ৰ সলনি **3-gatsu no Lion**।
