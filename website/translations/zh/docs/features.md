# 功能

**Nekoyomi** 保留了 [Aniyomi](https://github.com/aniyomiorg/aniyomi) 的全部功能，并在此基础上新增了许多内容。
以下是其中的亮点，每一项都附有详细说明的链接。
如需了解每个版本的全部更改，请查看[更新日志](/changelogs/)。

## 轻小说 {#light-novels}

- [轻小说](/docs/guides/novels)：第三种内容类型，拥有独立的书架、分类、更新和历史记录。
- [文本阅读器](/docs/guides/novels#reading)：可调节字体、字号、间距和边距，自动滚动还能接续到下一章。
- [本地小说](/docs/guides/novels#local-novels)：阅读你自己的 `.epub` 文件。

## 书架 {#library}

- [自定义系列](/docs/faq/library#how-do-i-group-several-entries-into-one-series)：将多个作品归入同一个文件夹，并使用独立的封面。
- [分组方式](/docs/faq/library#how-do-i-group-my-library-by-source-status-or-tag)：按图源、状态、语言、标签或进度记录状态分组，不会影响你的分类。
- [标签筛选](/docs/faq/library#how-do-i-filter-my-library-by-tags)：按标签显示或隐藏作品。
- [置顶](/docs/faq/library#how-do-i-keep-entries-at-the-top-of-a-category)：让你最喜欢的作品始终排在最前面。
- [分类选项](/docs/guides/categories#category-options)：私密分类，以及为每个分类设置默认阅读模式。
- [观看和阅读次数](/docs/faq/library#how-do-i-see-how-many-times-i-ve-watched-or-read-something)：查看每一集或每一章你已看完或读完多少次，并可按此排序。

## 播放器和阅读器 {#player-and-reader}

- [长按加速](/docs/guides/video-player/#long-press)：长按即可 2 倍速播放，滑动可调整速度。
- [在线字幕](/docs/guides/video-player/sheets#search-opensubtitles)：无需离开播放器即可搜索 OpenSubtitles。
- [自动切换备用图源](/docs/guides/player-settings/internal-player-settings#automatic-source-fallback) *（实验性）*：当某个图源没有视频时，自动切换到另一个图源。
- [减少画面撕裂](/docs/guides/player-settings/decoder#reduce-screen-tearing) *（实验性）*。
- [条漫自动滚动](/docs/guides/reader-settings#auto-scroll)：解放双手阅读，速度可调。

## 浏览和迁移 {#browse-and-migration}

- [批量迁移](/docs/guides/source-migration#migrating-several-series-at-once)：一次迁移多部作品。
- [图源优先级](/docs/guides/source-migration#source-priority)：选择优先搜索哪些图源。
- [新版漫画插件](/docs/faq/browse/extensions#which-repositories-can-i-add)：支持 tachiyomix 1.6 格式，Keiyoushi 等仓库都在使用该格式。
- [从应用内导入](/docs/guides/local-manga-source/#importing-from-the-app)：无需文件管理器即可将文件添加到本地图源。

## 外观和体验 {#look-and-feel}

- [导航栏](/docs/faq/settings#how-do-i-customize-the-navigation-bar)：选择标签页并调整顺序，还可以使用透明度、模糊程度和高度均可调节的悬浮导航栏。
- [应用图标](/docs/faq/settings#how-do-i-change-the-app-icon)：包括由社区设计的图标。
- [封面背景](/docs/faq/settings#how-do-i-change-the-blurred-cover-behind-entries)：每个作品都会在标题区域后方以模糊横幅的形式显示其封面。
