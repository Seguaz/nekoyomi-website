# 常规
常见问题

## 什么是 Nekoyomi？ {#what-is-nekoyomi}
**Nekoyomi** 是一款免费、开源的 Android 应用，可用于观看动画以及阅读漫画和轻小说。
它是 [Aniyomi](https://github.com/aniyomiorg/aniyomi) 的分支，而 Aniyomi 本身基于 [Mihon](https://github.com/mihonapp/mihon)，Nekoyomi 保持与它们的插件和备份兼容。

## 为什么 Nekoyomi 没有上架 Google Play Store？ {#why-isn-t-nekoyomi-on-the-google-play-store}
**Nekoyomi** 不会上架 **Google Play Store**。

基于 APK 的插件与 [Google Play 的内容政策](https://play.google.com/about/developer-content-policy/)相冲突。
**Google** 可能会因某些内容而下架该应用，开发者希望避免这种情况。

请仅从[下载页面](/download/)或[官方 GitHub 仓库](https://github.com/Seguaz/Nekoyomi/releases)下载 **Nekoyomi**。

## Nekoyomi 有 iOS/iPadOS 版本吗？ {#is-nekoyomi-available-for-ios-ipados}
目前没有 iOS 或 iPadOS 版本，也没有相关计划。
由于 iOS 和 Android 应用的代码库各自独立，移植非常困难。

任何自称“**iOS 版 Nekoyomi**”的应用都与我们无关，应视为诈骗。

## 可以阅读轻小说吗？ {#can-i-read-light-novels}
可以！
**Nekoyomi** 设有专门的**小说**板块，拥有独立的书架、分类和文本阅读器。
与漫画和动画图源一样，小说图源来自小说插件仓库。
请参阅[轻小说指南](/docs/guides/novels)开始使用。

## Nekoyomi 有主屏幕小部件吗？ {#does-nekoyomi-have-home-screen-widgets}
有。除了封面网格小部件外，还有 **更新（列表）** 和 **动画更新（列表）** 小部件，可显示你的最新更新，包括封面、标题以及新章节或新剧集。

## Nekoyomi 相比 Aniyomi 增加了什么？ {#what-does-nekoyomi-add-over-aniyomi}
轻小说、自定义系列文件夹、书架分组和标签筛选、批量迁移、在线字幕、悬浮导航栏、社区设计的应用图标，以及更多功能。
请查看[完整功能列表](/docs/features)。

## 可以使用 Aniyomi 或 Mihon 的备份吗？ {#can-i-use-my-aniyomi-or-mihon-backup}
可以。
**Nekoyomi** 可以恢复由 **Aniyomi** 和 **Mihon** 创建的备份。
有关详细信息和限制，请参阅[备份指南](/docs/guides/backups)。
