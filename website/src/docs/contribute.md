# Contribute
Find out how to help build, translate or support the app.

## Code
Know how to code and want to improve something or you generally want to support the creation of the app?

- **App:** [Seguaz/Nekoyomi](https://github.com/Seguaz/Nekoyomi) on GitHub.
- **Website:** [Seguaz/nekoyomi-website](https://github.com/Seguaz/nekoyomi-website) on GitHub.

Pull requests are welcome.
For major changes, please open an issue or talk to us on [Discord](https://discord.gg/ZAUadQD5EM) first, so we can discuss what you would like to change.

## Translation
Want to help translate the app to your language?

Translations live in the app repository as Android string resources:

- `i18n/src/commonMain/moko-resources/<language>/strings.xml`
- `i18n-aniyomi/src/commonMain/moko-resources/<language>/strings.xml`

Edit the file for your language and open a pull request, or reach out on [Discord](https://discord.gg/ZAUadQD5EM) if you need help getting started.

## Bug reports and ideas
Not a coder or translator? You can still help a lot:

- Report bugs and suggest features on [GitHub](https://github.com/Seguaz/Nekoyomi/issues) or in our [Discord server](https://discord.gg/ZAUadQD5EM).
- Help other users in the Discord support channels.
- Found a mistake in these guides? Use the **Help us improve this page** link at the bottom of any page.

## Donations
Enjoying **Nekoyomi** and want to support its development?
You can make a donation on [Ko-fi](https://ko-fi.com/seguaz_).

Donations are entirely optional. **Nekoyomi** is free for everyone.

## Security
Found a security problem in the app or the website?
Please **don't** open a public issue.
Report it privately through [GitHub security advisories](https://github.com/Seguaz/Nekoyomi/security/advisories/new) instead.
